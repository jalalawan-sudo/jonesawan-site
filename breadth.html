How this is built. Daily closes from Yahoo Finance via the yfinance library, pulled by breadth_refresh.py and inlined into this page at build time. Percentages are simple close-to-close changes over 1, 5, 21 and 63 trading days plus year-to-date from the first close of the year. Prices are not dividend-adjusted, so total return on the longer horizons will differ.

On “live”. This page is static. It shows the data it was built with, which is why the timestamp is in the dateline rather than a flashing indicator. A browser cannot run yfinance, and the free quote endpoints that would allow a client-side refresh either send no CORS headers or rate-limit immediately. Re-running the refresh script takes a few seconds; during market hours the last bar is the live intraday print, so the numbers do move intraday.
